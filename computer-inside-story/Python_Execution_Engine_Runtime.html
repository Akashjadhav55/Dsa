How Python Actually Executes Code: Complete Internal Pipeline

Python is neither a purely interpreted nor a traditional natively-compiled language. It operates as a two-phase hybrid architecture: an initial front-end (Lexer, Parser, AST, and Bytecode Compiler) compiles raw scripts into bytecode instructions (.pyc), which are then executed on the Python Virtual Machine (PVM) runtime, allocating dynamically managed PyObject entities on a private heap with automatic reference counting and generational garbage collection.

Front-End Lexer + PEG Parser
Intermediate Form Stack Opcodes (.pyc)
Execution Core PVM (ceval.c Loop)
Memory Model PyObject + Dual GC

          3. Detailed Architectural Breakdown of Every Stage
        

        

          Exhaustive engineering rationales ("Why Is It Important?") and
          mechanical descriptions ("What Does It Do?") for each phase.
        

      


      

        
        

          
          

            

              

                
                   Why Is It
                  Important?
                
                

                  Software must be authorable, reviewable, and
                  version-controlled by humans in clean syntax. Furthermore,
                  real-world systems cannot be static: they require dynamic
                  runtime configuration through command-line flags (sys.argv), standard inputs (sys.stdin), and runtime configuration strings.
                

              

              

                
                   What Does It Do?
                
                

                  When you execute
                  python app.py --workers 4, the operating system launches the CPython executable.
                  CPython parses invocation arguments, configures standard
                  streams (sys.stdin, stdout,
                  stderr),
                  initializes system paths, reads the raw byte sequence of the
                  target script, and hands it over to the tokenizer.
                

              

            

          

        


        
        

          
          

            

              

                
                   Why Is It
                  Important?
                
                

                  A parser cannot effectively operate on unstructured continuous
                  character arrays. Whitespaces, inline comments, and
                  indentation depth (which defines Python's block scoping) must
                  be converted into discrete, formalized tokens to enable
                  unambiguous grammatical analysis.
                

              

              

                
                   What Does It Do?
                
                

                  CPython's internal tokenizer (Parser/tokenizer.c) scans the source character by character. It generates token
                  tuples comprising token types (e.g.,
                  NAME,
                  NUMBER,
                  OP,
                  INDENT,
                  DEDENT,
                  NEWLINE) and
                  precise line/column coordinates.
                

              

            

          

        


        
        

          
          

            

              

                
                   Why Is It
                  Important?
                
                

                  Tokens alone have no semantic hierarchy. The parser enforces
                  language grammar rules and guarantees structural validity
                  before any execution occurs. If brackets are unclosed or
                  syntax is malformed, the process halts immediately with
                  precise
                  SyntaxError
                  diagnostics.
                

              

              

                
                   What Does It Do?
                
                

                  CPython uses a high-performance **PEG (Parsing Expression
                  Grammar)** parser (introduced in Python 3.9). It consumes the
                  token stream and builds an in-memory **Abstract Syntax Tree
                  (AST)** composed of nodes like
                  FunctionDef,
                  BinOp,
                  Call, and
                  Return.
                

              

            

          

        


        
        

          
          

            

              

                
                   Why Is It
                  Important?
                
                

                  Traversing a rich nested tree structure during program
                  execution is computationally slow. Compiling the AST down to a
                  compact, linear array of numerical opcodes allows the virtual
                  machine to dispatch instructions with minimal branch
                  mispredictions and blazing-fast cache locality.
                

              

              

                
                   What Does It Do?
                
                

                  The compiler walks the AST, organizes flow control into a
                  Control Flow Graph (CFG), performs peephole optimizations
                  (constant folding like
                  24 * 60 -> 1440), and produces a
                  PyCodeObject
                  containing raw bytecode bytes (co_code), constants (co_consts), and variable symbol tables (co_varnames).
                

              

            

          

        


        
        

          
          

            

              

                
                   Why Is It
                  Important?
                
                

                  No production software is written in isolation. Python
                  programs depend heavily on standard modules (math, os) and
                  external compiled libraries (numpy, pandas). An
                  efficient module subsystem prevents redundant file parsing and
                  seamlessly links compiled C/C++ machine code into Python's
                  address space.
                

              

              

                
                   What Does It Do?
                
                

                  On an
                  import foo
                  statement, the import engine searches
                  sys.path. If
                  found, it checks
                  sys.modules. If
                  absent, it loads the bytecode (or uses dynamic linkers like
                  dlopen on POSIX
                  / LoadLibrary on
                  Windows for C-extensions) to initialize a new
                  PyModuleObject
                  and bind it to the caller's global namespace.
                

              

            

          

        


        
        

          
          

            

              

                
                   Why Is It
                  Important?
                
                

                  Physical CPUs cannot directly understand Python opcodes. The
                  PVM acts as a virtualized software CPU emulator that abstracts
                  away diverse CPU microarchitectures (x86_64, ARM64, RISC-V),
                  delivering write-once, run-anywhere cross-platform execution.
                

              

              

                
                   What Does It Do?
                
                

                  CPython executes an evaluation loop (_PyEval_EvalFrameDefault
                  in
                  Python/ceval.c).
                  For each bytecode instruction, it pops operands off the local
                  value stack, computes the operation (or invokes C functions),
                  pushes return values, and manages activation frames (PyFrameObject) for recursion and exceptions.
                

              

            

          

        


        
        

          
          

            

              

                
                   Why Is It
                  Important?
                
                

                  Python's dynamic typing requires every value to carry its own
                  metadata (type and reference count). Developers never need to
                  manually declare data types or calculate memory sizes (sizeof) or allocate memory pointers (malloc) because runtime objects self-describe.
                

              

              

                
                   What Does It Do?
                
                

                  When you assign
                  x = 1000,
                  CPython allocates a
                  PyLongObject
                  in its private heap using PyMalloc (an
                  optimized memory allocator using Arenas, Pools, and Blocks).
                  The object is populated with
                  ob_refcnt = 1, a
                  pointer to
                  &PyLong_Type,
                  and the binary representation of 1000.
                

              

            

          

        


        
        

          
          

            

              

                
                   Why Is It
                  Important?
                
                

                  Without automated memory reclamation, continuous allocations
                  would quickly cause physical RAM exhaustion (memory leaks) and
                  crash applications. Python's dual approach guarantees
                  predictable, immediate deallocation for 95% of objects without
                  long garbage collection pauses.
                

              

              

                
                   What Does It Do?
                
                

                  1. Reference Counting: Each assignment
                  increments
                  ob_refcnt;
                  removals decrement it. When it reaches 0, the object's memory
                  is instantly freed.

                  2. Generational Cyclic GC: To handle isolated
                  circular loops (A.child = B; B.parent = A), CPython groups container objects into three generations
                  (Gen 0, 1, 2) and runs cycle-detection algorithms to reclaim
                  unreferenced isolated islands.
                

              

            

          

        


        
        

          
          

            

              

                
                   Why Is It
                  Important?
                
                

                  At the final physical boundary, all software is electricity
                  flowing through silicon transistors. The OS protects hardware
                  resources and provides standardized interfaces for file I/O,
                  networking, and multi-threaded CPU scheduling.
                

              

              

                
                   What Does It Do?
                
                

                  When a Python script calls
                  print("Done")
                  or reads from disk, the PVM issues underlying C runtime system
                  calls (write()
                  or read())
                  through OS trap instructions, transitioning into kernel space
                  to flush data to terminal stdout, disk storage, or network
                  network buffers.
